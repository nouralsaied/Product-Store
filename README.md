# Product Store

A responsive React product catalog built with Vite and Tailwind CSS. Products
are fetched from the [DummyJSON Products API](https://dummyjson.com/docs/products).

## Features

- Product cards showing the image, name, rating, and price.
- Eight products per page with numbered pagination.
- Loading, error, and empty-result states.
- Responsive header navigation and product grid.

## Getting started

Install dependencies and start the development server:

```sh
npm install
npm run dev
```

Run the code checks and create a production build:

```sh
npm run lint
npm run build
```
